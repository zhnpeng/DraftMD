# DraftMD Changelog

欢迎来到 DraftMD 的可玩更新说明。左侧面板列出本目录中的演示文件，可以直接打开体验。

## 0.1.1

- 支持 Responses API 与 Chat Completions 切换，以及模型列表同步。
- Agent 移至可调整宽度的右侧栏，导出内容不包含应用侧栏。
- 按模型配置推理强度，保存后通过相同配置重新测试能力。
- 打开文件夹后自动展开左侧文件列表并回到根目录；修复关闭所有窗口后的打开文件夹操作。
- 大文档使用仅渲染可见区域的源码编辑器，改善输入与保存期间的响应。
- 源码加入 Windows x64 候选适配；本次仅发布 macOS Universal 安装包。
- 安装包仍未签名、未公证，自动更新尚未启用。

## 0.1.0

- 发布 macOS Universal 正式版本；当前安装包未签名、未公证。
- 修复切换会话后的任务恢复、流式回复和待审批状态。
- 支持停止 Chat 请求，保护运行中会话，并改善小窗口审批布局。
- 启动时清理无任务引用且超过 30 天的快照，数据库恢复异常时保留快照。
- 修改模型连接或凭据后重新验证能力，避免旧连接测试结果覆盖新配置。
- 加强正式安装包的启动边界与自动验收。

## 0.1.0-preview.5

- 建立 DraftMD 产品名称、应用标识与 MIT 归属说明。
- 聚焦 macOS 13 及以上版本，提供 Apple silicon 与 Intel 通用构建。
- 保留实时文件同步、所见即所得编辑、内置主题、PDF 与 HTML 导出。
- 暂不提供 Word、阅读页图片、自定义主题导入和用户新建窗口功能。
