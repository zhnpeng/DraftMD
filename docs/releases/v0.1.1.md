# DraftMD 0.1.1

DraftMD is an open-source macOS AI Markdown editor. This regular release provides a freshly built Universal application for Apple silicon and Intel, following successful personal use by the release owner.

> **Unsigned macOS release:** the app has no Apple Developer ID signature and is not notarized. Gatekeeper may block the first launch. Automatic updates remain disabled.

## Install or Update

1. Download `DraftMD-0.1.1-universal.dmg`, quit any running DraftMD instance, and drag DraftMD into Applications, replacing the older app if present.
2. Control-click the app in Applications and choose **Open**, then confirm if offered.
3. If blocked, use **System Settings > Privacy & Security > Open Anyway** to confirm the launch.

Do not disable Gatekeeper globally. The ZIP contains the same application as an alternative download. Updates are manual; replacing the application does not intentionally replace your documents or local profile. Back up important work before updating.

## Changes Since 0.1.0

- **Responses API and model discovery:** choose Responses API or Chat Completions for OpenAI and compatible endpoints. Synchronize available models and use provider-aware suggestions. Existing configurations retain their selected protocol; failed requests never silently switch protocols.
- **Right-hand Agent sidebar:** a resizable, collapsible sidebar keeps the editor central, with document and selection context, streaming replies, tool activity and deletion approvals. PDF/HTML exports exclude the application sidebar.
- **Per-model reasoning effort:** save a reasoning level for known supporting models or keep the provider default. Capability tests use the saved setting, and unsupported combinations remain hidden. Higher effort can increase latency and token use; support depends on the actual service and model.
- **Workspace navigation fixes:** opening a workspace automatically reveals its root file list, even if the panel was hidden or showing the outline. You can still collapse it manually; background file changes do not reopen it. Open Folder works after all macOS windows have closed.
- **Platform and packaging regressions:** expand packaged acceptance for native modules, Unicode image paths, provider settings and workspace interactions.

Workspace-scoped Agent tools, approval before deletion, local task history, Diff and conflict-aware Undo remain available. Chat-only configurations receive no file tools. Credentials stay in the OS credential store.

## Windows Candidate, Not a Windows Release

The source includes Windows x64 adaptation and a separate candidate CI workflow, covering native window/menu behavior, Ctrl shortcuts, file launching, credential storage, path guards and NSIS/ZIP packaging. **No Windows installer is published in this release.** Real Windows runtime and installer acceptance are still required. See [Windows acceptance](https://github.com/zhnpeng/DraftMD/blob/v0.1.1/docs/windows.md).

## Validation and Known Limits

The Release workflow must pass type checking, tests, security, end-to-end and performance gates, theme checks, Universal/native-module verification and acceptance against the actual packaged app before uploading release assets. Consult the workflow for this tag for exact results; earlier candidate reports do not verify this binary.

- macOS 13+ is the packaging target; physical Intel and macOS 13 runtime checks remain outstanding.
- Developer ID signing, notarization and stapling have not been performed.
- Automated provider fixtures and personal use do not establish compatibility with every cloud service, Ollama, LM Studio, endpoint or model. Consult [provider compatibility](https://github.com/zhnpeng/DraftMD/blob/v0.1.1/docs/provider-compatibility.md).
- Windows ARM, Linux, mobile and Web are not supported release targets.
