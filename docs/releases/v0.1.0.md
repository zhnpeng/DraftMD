# DraftMD 0.1.0

DraftMD is an open-source macOS AI Markdown editor. This is a regular GitHub Release, with a Universal application containing Apple silicon and Intel architectures.

> **Unsigned macOS release:** the application is not signed with an Apple Developer ID and is not notarized by Apple. GitHub does not require signing to publish a release. macOS Gatekeeper may block the first launch.

## Install on macOS

1. Download `DraftMD-0.1.0-universal.dmg` and drag DraftMD into Applications.
2. In Applications, Control-click DraftMD, choose **Open**, then confirm **Open** if offered.
3. If macOS blocks it, open **System Settings > Privacy & Security > Open Anyway**, then confirm the launch.

Do not disable Gatekeeper globally. The ZIP is an alternative download of the same application. Updates are installed manually; automatic updates are disabled.

## Included

- Visual and source Markdown editing, external file synchronization, and unsaved-edit protection.
- Folder navigation, document outline, twelve themes, task lists, KaTeX, Mermaid, and PDF/HTML export.
- Anthropic, OpenAI, and OpenAI-compatible provider configuration with capability testing and Keychain credential storage.
- Workspace-scoped Agent file tools, streaming replies, deletion approval, task history, Diff, and conflict-aware Undo. Chat-only models provide text replies without file tools.

## Changes Since Preview 5

- Running Agent and Chat tasks resume correctly when switching conversations, including streamed output and pending approvals.
- Stop and window close cancel requests; active sessions and model settings are protected from conflicting changes.
- Approval buttons remain accessible in smaller windows.
- Startup cleanup removes only unreferenced snapshots older than 30 days, preserving task history and pausing cleanup when database recovery may have lost references.
- Changing a provider connection or credentials requires a new capability test; stale results for a different connection cannot overwrite the saved result.
- Packaged applications ignore development renderer URLs and load their bundled interface.
- Release automation checks the built application as well as source tests, security, performance, themes, and Universal/native-module packaging.

## Validation Limits

macOS 13 or newer is the support target. Physical Intel Mac testing and runtime testing on macOS 13 remain outstanding; architecture inspection and Rosetta checks do not replace them. Live paid-provider, Ollama, and LM Studio compatibility still needs verification against specific services and models. Signing, notarization, and stapling have not been performed.

See the Release workflow attached to this tag for the automated build and test results. Source licensing remains MIT, with ColaMD attribution and third-party notices bundled in the application.
