# DraftMD 0.1.0 Preview 4

> **Unsigned macOS preview:** this build is not signed with an Apple Developer ID and is not notarized by Apple. macOS Gatekeeper may block a normal first launch. Do not treat this preview as a production-trusted release.

## Install on macOS

1. Download `DraftMD-0.1.0-preview.4-universal.dmg`.
2. Open the DMG and drag DraftMD into Applications.
3. In Applications, Control-click DraftMD, choose **Open**, then confirm **Open**. If macOS still blocks it, use **System Settings → Privacy & Security → Open Anyway**.

Do not disable Gatekeeper globally.

## Included

- Native Markdown editing with visual and source modes.
- External file change synchronization with unsaved-edit protection.
- Files and document outline navigation.
- Task lists, highlights, KaTeX, Mermaid, search, and smart line breaks.
- Twelve built-in themes and PDF/HTML export.
- Local AI agent workflows with Anthropic, OpenAI, and OpenAI-compatible provider configuration.
- Universal `arm64 + x86_64` macOS application for macOS 13 or newer.
- MIT-licensed source with preserved ColaMD attribution and bundled third-party notices.

## Verification status

Automated type, unit, integration, security, end-to-end, performance, theme, and production-build checks pass. The Universal package is verified for both architectures and includes `LICENSE` and `NOTICE.md`.

This preview has not completed:

- Apple Developer ID signing, notarization, or stapling.
- Physical Intel Mac testing.
- Runtime testing on macOS 13.
- Live paid-provider verification.

Please report non-sensitive defects through GitHub Issues. Report vulnerabilities privately through the repository Security tab.
