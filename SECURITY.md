# Security Policy

## Supported versions

Until DraftMD publishes its first stable release, security fixes are applied to the latest commit on the default branch only.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** form in this repository's Security tab:

https://github.com/zhnpeng/DraftMD/security/advisories/new

Include the affected version or commit, impact, reproduction conditions, and any suggested mitigation. Do not include real credentials or private documents. You should receive an initial acknowledgement through the private advisory within seven days.

If private vulnerability reporting is temporarily unavailable, wait for it to be restored rather than publishing exploit details in an issue. Non-sensitive hardening suggestions may be filed as regular issues.

## Scope

Security reports may cover the desktop application, IPC boundary, file-system boundary enforcement, provider credential handling, update flow, exported documents, bundled iOS reader, or VS Code extension.
